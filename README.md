# Freshers Admin Portal

Private management portal starter for volunteer/organizer administration, daily duty authorization, QR verification and access logs.

## Run

1. Install Node.js 20+.
2. `npm install`
3. `npm run dev`
4. Open `http://localhost:3000/login`

## Important

This starter intentionally uses mock UI/data. Before production, replace the simulated login and data with server-side authentication, PostgreSQL/Prisma, secure QR tokens, RBAC, audit logs, rate limiting, validation, backups and monitoring.
